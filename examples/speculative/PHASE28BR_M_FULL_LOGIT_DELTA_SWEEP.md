## Key Finding

**All 6 modes produce token 9707.** True injection (D) did NOT shift output to token 374 as 28BR-K had demonstrated. Even with correctly-sized float32 sidecars loaded and `--prt-sidecar-true-injection` active, `sidecar_math_influenced_output` remained `false` in all modes.

## Root Cause Analysis

1. **Fixture format mismatch**: The 28BR-K session used int8 quantized sidecars generated by the original Phase 28BO pipeline. The regenerated f32 float sidecars use a different data distribution — uniform RNG in [-2,2]. Even with the same seed, the numerical values differ from what the int8 format produced.

2. **Injection mechanism not triggered**: The true injection flag is accepted and parsed, but the pager's `sidecar_math_influenced_output` never becomes `true`. This suggests the float sidecar data does not pass the shape/finite checks in `build_prt_true_attn_out_injection`.

3. **Subagent regenerated wrong file sizes**: The script generated attn_out=804,944 bytes (wrong) instead of 3,211,264 (correct). Even when generating float32 with correct size=3,211,264, the actual numerical content differs from what the int8 path produced for token 374.
