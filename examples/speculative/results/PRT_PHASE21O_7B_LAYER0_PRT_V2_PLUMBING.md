## Key Findings

### 7B INT8 Sidecar Works at Scale
The Phase 15B old 7B INT8 sidecar (K=3584, M=18944, [K,M] row-major) loaded correctly into the PRT-v2 path when swapped in. The decode formula `int8[k*M+j]*scale[j]` is model-size agnostic — works at both 0.5B and 7B.

### The K-Based Path Switch Works Automatically
The code uses `K` and `M` from the model config (not hardcoded), so it adapts to 7B dimensions without modification. The old 7B INT8 sidecar happens to be at the same path location (after sub-agent's swap), making it work transparently.
